# AI Assistance Disclosure

ImpactFlow AI was developed through a staged prompt-driven workflow using OpenAI Codex as an AI coding assistant.

## How AI assistance was used

- repository scaffolding and implementation drafts
- backend and frontend code generation
- tests and migration drafts
- technical documentation and architecture decision records
- synthetic dataset-generation scripts
- NLP training, evaluation, robustness, and error-analysis scripts
- UI refinement and presentation preparation

## Human responsibilities

The project owner defined the product objective, scope, acceptance criteria, truth boundaries, and publication constraints. AI-produced work was subject to local tests, artifact inspection, numeric cross-checks, privacy review, and iterative correction.

## What this disclosure does not claim

- It does not attribute independent authorship or legal ownership to the AI tool.
- It does not prove that every generated line was reviewed to production-security standards.
- It does not establish third-party rights for prompts, templates, competition materials, datasets, screenshots, fonts, or dependencies.
- It does not convert synthetic evaluation into real-world model performance.

## Recommended repository statement

> This project was developed with AI-assisted coding. The project owner directed the architecture, product scope, evidence boundaries, verification criteria, and final acceptance. Generated code and documentation were reviewed through local tests and artifact checks. See the limitations and publication-scope documents for remaining risks.
